# People

1. Find the person by name, alias or role, in the people registry and in the notes that mention them. Search the name if no person note exists.
2. Open the notes linked to them: projects, events, places, organisations.
3. Give roles and actions with their dates; roles change, so check History.
4. "Who did X" questions: find X first, then the person on it.
5. What someone said is only known if a note records it. Otherwise, say it isn't recorded.
