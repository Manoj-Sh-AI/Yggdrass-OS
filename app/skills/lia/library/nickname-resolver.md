# Nickname resolver

1. Treat the question's wording as a description. Match it against aliases, about lines and facts, and translate German or English if needed. A phrase like "my side project", "that course thing" or "the work reports" points to whichever note's aliases or description fit it.
2. When more than one note fits, open them all and pick by the facts. If they still tie, say which ones you mean.
3. Answer from the resolved note. Start with a short confirmation if the match isn't obvious ("Taking that as your thesis: …").
4. A placeholder like "[company]", or a name no note has, stays unresolved: say so, after searching.
