# Fact lookup

1. Find the note whose title, about line or aliases match the thing asked about. When two notes could hold it, open both.
2. Read Facts for the exact attribute asked: the date, the amount, the role.
3. If History shows the value changed, give the current one, and the old one only if it helps.
4. Answer in one or two sentences, with the footnote.
