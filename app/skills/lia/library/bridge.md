# Bridge

1. Split the question into its sides: two notes, two areas, or a thing and a goal.
2. Open the notes for every side in one call. Hubs help you find an area's notes.
3. For each pair of sides, look for what joins them: a shared skill, tool, person, place, date or constraint, or a link line. Write one sentence per connection, citing the fact on each side.
4. If you compute between facts, show both values and the result.
5. Before you say the sides don't connect, search with each side's key terms. Then say what is and isn't recorded.
