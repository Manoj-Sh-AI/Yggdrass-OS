# Change over time

1. Words like "still", "before", "now", "changed" or "how long" mark this job. Open every note about the thing, and read `## History` as well as `## Facts`.
2. Find the earlier state (History, an `until:` date, an "as of" date) and the current state (Facts).
3. Answer in the order earlier → now, with a citation for each, and say when the change happened.
4. If only one side is recorded, give it and say the other is missing. Never infer a change from the `updated` date in a map row.
