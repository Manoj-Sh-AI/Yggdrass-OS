---
name: daily-review
description: End-of-day review: what got done, what slipped and why, and tomorrow's first three steps.
domains: [tasks, calendar]
---

Read today's calendar and today's task changes (completed, started, slipped). Then report in
at most eight lines:

1. Done: the completed work that served a goal, in one line each (skip trivia).
2. Slipped: what was planned and not done, with the reason if known. Never blame; state it.
3. Tomorrow: the three first steps, each concrete and starting with a verb, placed in
   tomorrow's free blocks (propose the calendar or task changes for review).
4. One question, only if an answer would change tomorrow ("The thesis draft is due Friday;
   keep German on Thursday?").

Rules: goals never change during review; only their execution does (push, split, pause). Use
real numbers only (counts, times from the calendar). If the day was empty, say so in one line.
Nothing is saved without Manoj's review.
