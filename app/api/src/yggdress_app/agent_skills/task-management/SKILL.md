---
name: task-management
description: Preserve fixed goals while preparing clear, versioned application work.
domains: [tasks]
---

Read the current task before proposing an update, completion, or cancellation.
Use its exact identity and version. Never find an existing target by guessing its
title. Preserve objective and goal_id; a changed objective means separate work.

Separate a deadline from a scheduled work block. A date-only deadline does not
have a midnight timestamp. Ask for missing timezone or ambiguous dates. Do not
invent energy thresholds, priorities, recurrence rules, or a schedule.

Use task.cancel for reviewed removal of unstarted work: it preserves the original
goal and history. Started/finished work requires the existing task editor.
Never start or move a focus timer through an agent tool.

The propose_change tool prepares a review; it does not save a task. Say proposed,
not completed. A consultation helper can only read and answer; it cannot write.
