# A workspace with less noise

User direction, 2026-11-14. Applies across the platform, not only Today.

- Remove demo cards, synthetic AI answers, canned insights, motivational filler, simulated notification controls and redundant shortcuts from the active workspace.
- Keep the working Notes, Tasks, Calendar and Brain graph. Do not delete user records, drafts, application capabilities or Brain data to simplify presentation.
- Today shows real application commitments and a user-selected or already running task. Do not invent priorities, choose goals or add adaptation rules.
- Use clear page names and stable navigation. Secondary controls remain discoverable behind named disclosures; errors, save review, conflict warnings and Undo remain visible where relevant.
- Use the existing nature and glass treatment with readable surfaces. Continuous graph rotation starts paused; existing motion/transparency preferences remain available.
- Retire demo Dashboard/area entry points from the active UI. Keep their source/data recoverable; old links route to working pages.
- Search and capture must lead to the connected Notes application, never synthetic notes or a simulated agent answer.
- This is cognitive accessibility work, not a clinical claim. Individual needs vary. No new agents, memory-engine changes, energy thresholds or notification infrastructure.

Verify actual data, empty/error states, keyboard access, task execution/reload, real Notes search navigation, desktop/phone layout and build. No real Brain writes during verification.
