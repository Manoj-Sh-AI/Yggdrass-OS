# Yggdress interface experience

User direction recorded 2026-11-13, superseding visual density choices in earlier material studies.

- Yggdress should feel like a personal place in nature that supports daily life. This is an experience goal, not a medical claim.
- Keep signal; remove redundant presentation, decorative controls and components without a useful role. Prefer progressive disclosure for secondary information. Minimal presentation must retain useful functionality.
- Prioritize immediate, reliable interaction over ornamental animation. Save feedback must remain truthful; never imply a database commit before success.
- Keep the landscape, neutral smoked-glass material, readable text, clear next actions and an unhurried spatial rhythm. Avoid colouring every surface green.
- Motion explains cause, position or state. Keep it short, interruptible where applicable and optional. Respect motion, transparency and contrast preferences.
- Use Apple human-interface principles and relevant minimalist design research as inputs, adapting them to this web application. Do not copy proprietary assets or impose a community skill's marketing-site patterns.
- Preserve user data, drafts, confirmations, accessibility, authentication and architectural boundaries while simplifying the interface.
- Application engineering continues to own frontend integration. AI-agent implementation and changes to Lia's memory engine are outside this visual/interaction task.

Acceptance for each iteration: show the actual implemented design, verify desktop/phone behavior, exercise affected interactions and failures, and report which changes are in the study, verified application source or the running application. Do not claim measured performance improvements without evidence.
