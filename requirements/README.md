# Requirements

The source of truth the agent builds from. Lifecycle steps 1 (requirements) and the spec live here.

## Workflow

1. Copy `_scoping-template.md` to `scoping-<feature>.md` and answer all six questions yourself.
2. If you cannot answer questions 3 and 6, you are not ready to build.
3. Copy `_spec-template.md` to `spec-<feature>.md` and write testable acceptance criteria.
4. Only then move to `planning/`.

## Files

- `_scoping-template.md`: the six scoping questions
- `_spec-template.md`: spec skeleton

One scoping file and one spec per phase of `planning/locked-plan-v1.md`. First to scope: **phase 1a** (brain files, links, gateway skill), as `scoping-phase-1a.md`.
